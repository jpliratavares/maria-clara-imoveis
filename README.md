# Maria Clara Andrade França — Imóveis

Site para corretora independente em João Pessoa e região.

## Desenvolvimento

```bash
npm install
npm run dev
```

## MVP

- Página inicial e apresentação pessoal
- Catálogo demonstrativo de venda e aluguel
- Filtros por tipo, cidade e finalidade
- Detalhes dos imóveis
- Contato reservado com `href="#"` até a configuração do WhatsApp

**Importante:** anúncios, valores e fotografias de imóveis demonstrativos não são anúncios reais. Antes da publicação: informar CRECI verdadeiro, aprovar textos e fotos, substituir anúncios de demonstração e configurar contato.

Stack: React, TypeScript, Vite, React Router e Lucide.
